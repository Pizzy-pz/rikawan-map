# 1-2. 新規登録画面 SP


## ワイヤーフレーム

```
┌─────────────────────────────┐
│                             │
│      ① 新規登録             │
│   アカウントを作成してください│
│                             │
│   メールアドレス            │
│  ┌───────────────────────┐  │
│  │ ② example@mail.com   │  │
│  └───────────────────────┘  │
│                             │
│   パスワード                │
│  ┌───────────────────────┐  │
│  │ ③ 8文字以上           │  │
│  └───────────────────────┘  │
│                             │
│   パスワード（確認）        │
│  ┌───────────────────────┐  │
│  │ ④ もう一度入力        │  │
│  └───────────────────────┘  │
│                             │
│  ┌───────────────────────┐  │
│  │  ⑤ アカウントを作成   │  │
│  └───────────────────────┘  │
│                             │
│  すでにアカウントをお持ちの方は│
│         ⑥ ログイン          │
│                             │
└─────────────────────────────┘
```

## 機能詳細

| 番号 | 機能名 | 詳細 | 挙動 | 遷移先 |
|---|---|---|---|---|
| ① | タイトル・キャッチコピー | 「新規登録」と「アカウントを作成してください」を表示 | - | - |
| ② | メールアドレス入力 | type=email。必須。プレースホルダー: example@mail.com | テキスト入力 | - |
| ③ | パスワード入力 | type=password。必須。8文字以上。プレースホルダー: 8文字以上 | テキスト入力（マスク） | - |
| ④ | パスワード確認入力 | type=password。必須。③と一致する必要あり。プレースホルダー: もう一度入力 | テキスト入力（マスク） | - |
| ⑤ | アカウントを作成ボタン | Supabase Auth でアカウント作成。失敗時はエラーメッセージを表示 | クリックで登録処理 | 成功: 2-1 店舗一覧 |
| ⑥ | ログインリンク | テキストリンク | クリックで遷移 | 1-1 ログイン |
