│                             │
│ ④ サンプル（店舗名）        │
│                             │
│ ┌─────────────────────────┐ │
│ │ メモ                    │ │

## 機能詳細

| 番号 | 機能名 | 詳細 | 挙動 | 遷移先 |
|---|---|---|---|---|
| ① | 戻るボタン | 「＜ 戻る」と表示 | クリックで戻る | 2-1 店舗一覧 |
| ② | 編集ボタン | アウトラインボタン | クリックで遷移 | 2-4 店舗編集 |
| ③ | 削除ボタン | 赤色アウトラインボタン。確認ダイアログを表示してから実行 | クリックでダイアログ表示 → DB DELETE | 削除後: 2-1 店舗一覧 |
| ④ | 店舗名 | ページ上部に大きく表示 | - | - |
| ⑤ | メモカード | メモが存在する場合のみ表示。黄色背景のカード。「メモ」ラベル付き | - | - |
| ⑥ | Google マップでルートを確認ボタン | 緑色ボタン。タップで Google マップアプリ／Web を外部で開きルートを表示 | クリックで Google マップを外部起動 | - |
| ⑦ | Google マップ | 店舗の座標にピンを表示。Maps JavaScript API で描画 | - | - |
